# حبئ — مطعم عفرين

نسخة مستقلة قابلة للتعديل من موقع المطعم، مبنية كـ **Static Website** بدون قاعدة بيانات أو اشتراك في منصة بناء.

## تعديل الأسعار والمعلومات
افتح `site-data.js` وعدّل:
- الاسم والوصف
- رقم الهاتف وواتساب
- العنوان وساعات العمل
- أسعار وأسماء ووصف الأطباق
- المراجعات

## تغيير الصور
ضع الصور الجديدة داخل `assets/` وعدّل أسماء الملفات في `index.html` إذا أردت تغيير صورة معينة.

## التشغيل محلياً
يمكن فتح `index.html` مباشرة، أو تشغيله عبر أي خادم ملفات محلي.

## النشر المجاني
### Cloudflare Pages
1. ارفع المشروع إلى GitHub.
2. في Cloudflare Pages اختر إنشاء مشروع وربطه بالمستودع.
3. لأن الموقع static، لا يحتاج إلى قاعدة بيانات أو خادم.
4. كل تعديل تدفعه إلى GitHub يمكن نشره تلقائياً.

### GitHub Pages
1. أنشئ مستودعاً عاماً على GitHub.
2. ارفع الملفات كما هي.
3. Settings → Pages → اختر النشر من الفرع الرئيسي.
4. سيظهر رابط مجاني للموقع.

ملاحظة: شراء اسم نطاق خاص مثل `example.com` شيء منفصل عن الاستضافة المجانية.
